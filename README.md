# riley-overview

A GNOME-style Activities overview for the Riley desktop on Hyprland: one overlay per screen that spreads that
screen's windows out as live previews, with a workspace strip at the top, search, and drag and drop between
workspaces. Shown on demand; tiling stays as it is. Qt Quick (Quickshell).

Work in progress.
